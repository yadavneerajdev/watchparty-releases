<h1 align="center">WatchParty for macOS</h1>

<p align="center">Downloads and updates for the WatchParty desktop app.</p>

## Download

Get the latest version from the [Releases](../../releases/latest) page:

- **WatchParty-x.y.z-universal.dmg**: open it and drag WatchParty to Applications.
- **WatchParty-x.y.z-universal.pkg**: an installer that places WatchParty in Applications.

Both run natively on Apple silicon and Intel Macs with macOS 12 or later.

## Updates

WatchParty checks this page for new versions and updates itself.

## About

WatchParty lets friends watch together in private rooms. The desktop app adds browser tabs you can share straight into a room, with their sound, plus built-in ad and tracker blocking.
